# Proveniencia dos dados (data/aoe4/)

Subset (english + french) de unidades, construcoes, tecnologias, upgrades e civilizacoes
extraido do dataset publico **aoe4world/data** (https://github.com/aoe4world/data),
que reune "stats de unidades, construcoes, tecnologias... parseados dos arquivos do jogo,
refletindo o que os jogadores leem nas tooltips in-game".

- Upstream: https://github.com/aoe4world/data
- Conteudo copiado em 2025-10-08 (sessao de build), 1.2 MB, sem imagens/icones (assets do
  jogo original NAO sao usados no Crown of Ages; apenas numeros/textos de mecanica).
- Os numeros de docs/SPEC.md derivam deste dataset.

Repositorio do projeto: https://github.com/guhcostan/crown-of-ages
